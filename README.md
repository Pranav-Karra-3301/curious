## what is this

machines took over manual labor, so we invented gyms. now ai is taking over mental labor, so maybe we need mental gyms. curious is a simple one: one curious question every day at midnight EST, forever.

no algorithms, no personalization, no engagement metrics. everyone sees the same question at the same time, worldwide. just something to ponder throughout your day, then come back tomorrow for a new one.

## how it works

- a new question drops daily at midnight EST and stays the same for everyone all day
- questions are generated ahead of time and rotated on a schedule
- browse earlier prompts on the [past questions](https://curious.pranavkarra.me/past-questions) page
- more on the idea behind it on the [about](https://curious.pranavkarra.me/about) page

## tech

built with [Next.js](https://nextjs.org) and Tailwind CSS, deployed on Vercel. questions are generated with an LLM and served statically for the day.

## development

```bash
npm install
npm run dev
```

then open [http://localhost:3000](http://localhost:3000).
